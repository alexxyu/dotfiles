# Repository guidance

Read [README.md](README.md) before making changes. It documents the repository
structure, supported configurations, rebuild commands, and macOS preference workflow.

Keep README.md focused on repository structure, supported configurations, setup,
rebuild commands, and other high-level workflows. Update it only when those
documented topics change. Do not add low-level configuration details such as app
keybindings, individual settings, or preference values unless explicitly requested.
Keep those details in the relevant configuration files, with comments when useful.
